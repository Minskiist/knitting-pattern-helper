# Backlog

Ominaisuudet karkeassa tärkeysjärjestyksessä. Jokaisesta tehdään oma GitHub Issue.

## 1. Älykäs laskin
Laskee neuletiheydestä ja tavoitemitoista, kuinka iso kaavion täytyy olla.
- Syötteet: silmukkaa / 10 cm, kerrosta / 10 cm, tavoiteleveys (cm), tavoitekorkeus (cm)
- Tulokset: silmukkamäärä, kerrosmäärä, arvioitu koko (cm), silmukoita yhteensä
- Muistutus: kirjoneule ja palmikot joustavat vähemmän kuin sileä neulos
- "Tee kaavio" -nappi luo tyhjän ruudukon tulosten kokoisena (vaatii kohdan 2)

## 2. Kaavioeditori
Oman kaavion piirtäminen tyhjälle ruudukolle.
- Ruutujen maalaus klikkaamalla tai vetämällä
- Yhtenäisen alueen täyttö
- Värivalinta (vähintään pohja- ja kontrastiväri)
- Numerointi neulekaavion tapaan: silmukat oikealta vasemmalle, kerrokset alhaalta ylös

## 3. Toiston esikatselu
- Kuvioaihion toisto vaakaan ja pystyyn (määrä valittavissa)
- Näyttää, miltä kuvio näyttää isolla pinnalla

## 4. Näkymätyökalut
- Zoom editorissa
- "Käännä näkymä" (peilaus)

## 5. Editorista neulomaan
- Itse tehty kaavio siirtyy suoraan seurantatilaan ilman kalibrointia, koska ruudukko on jo tiedossa
